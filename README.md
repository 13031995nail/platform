# @timepath/tmobis

Монорепозиторий Платформы Т-Мобис

![Commitizen friendly](https://img.shields.io/badge/commitizen-friendly-brightgreen.svg)

## Установка
### Предварительные шаги
- Необходимо установить Node 16.* и Yarn, либо [Volta](https://volta.sh), которая автоматически подтянет нужные версии тулсов. 
  - Используемые версия тулсов также указаны в блоке volta файла package.json.
- Убедиться, что версия Yarn из репозитория подтянулась успешно с помощью команды `yarn -v`. Ожидаемый результат: 3.5.1.
- Убедиться, что в системе установлен PowerShell.
- НЕ УСТАНАВЛИВАТЬ РЕПО ПО ПУТИ, СОДЕРЖАЩЕМУ ПРОБЕЛЫ!!!

### Шаги установки
- Выполнить `yarn` в корне репозитория.
  - Первоначальное выполнение шага `Link step` может занимать до 20-30 минут в зависимости от диска.
- После установки пакетов можно переходить в нужные папки и выполнять необходимые действия над пакетами (`ember b`, `ember s` и тд).

## Участие
### Conventional commits
- В проекте используется методика [conventional commits](https://outline.t-mobis.ru/s/c7497734-8236-4db2-9302-3de8620936db).
- Для упрощения составления текста комитов добавлена консольная утилита Commitizen (`cz` или `yarn cz`).
- Для проверки соответствия текста комитов методике установлен Commitlint, выполняющий проверку при попытке комита и в мердж реквестах.
- В дальнейшем из текстов комитов генерируется `CHANGELOG.md`,
поэтому они должны быть максимально корректны.

## Публикация
### Публикация пакетов фронтенда
- Авторизоваться в Nexus FF через .yarnrc пользователя
- Выполнить `deployFrontend.ps1`
- Поднять версию пакетов в CLI

### Публикация пакетов бэкенда
- Авторизоваться в Nexus FF через dotnet nuget update source
- Поднять версию пакетов в Directory.Packages.props
- Выполнить `deployBackend.ps1`
