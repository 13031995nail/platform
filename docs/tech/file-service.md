# Файловый сервис

* Дата создания: 2025-05-09
* Дата обновления: 2026-05-18

* Статус: Реализовано

## Архитектурное решение

Файловая подсистема отделяет метаданные файла и операции получения/загрузки от конкретного способа хранения.

Бэкенд предоставляет:

* общий контракт файла;
* компонент чтения файлов;
* компонент загрузки;
* Flexberry адаптер для связывания файлов с сущностями и процессом обработки HTTP-запросов.

Фронтенд содержит сервис работы с файлами и компонент формы для просмотра/прикрепления.
