# Аудит сущностей Flexberry

- Дата создания: 2025-05-15
- Дата обновления:
- Версия: 1.0
- Статус: Реализовано

## Назначение

Механизм обеспечивает аудит работы с сущностями приложения: записи аудита сохраняются в базе данных и доступны через интерфейс приложения.

## Архитектура

Реализация основана на [Flexberry BigData Audit](https://tech.flexberry.org/fent_flexberry-auditbigdata.html) и интегрирована с платформенным модулем `FlexberryModule`.

На бэкенде `FlexberryModule` содержит настройки регистрации аудита:

- `ModelAssemblies` → `AuditRecord` — модель записи аудита;
- `ConfigureAudit` → `LegacyAuditManager` — используемый менеджер аудита.

На фронтенде формы просмотра аудита предоставляются пакетом `ember-flexberry-security` и переопределёнными для совместимости с Платформой классами в `@timepath/tmobis-core`.

## Хранение и просмотр

Записи аудита сохраняются в таблице `Audit`. Для их просмотра в приложении используется маршрут:

`new-platform-flexberry-audit-big-data-audit-record-l`

Общая схема взаимодействия по имеющемуся описанию:

```text
Работа с сущностями приложения
           ↓
Аудит на бэкенде через FlexberryModule
           ↓
       Таблица Audit
           ↓
Просмотр записей через формы фронтенда
```

## Ограничения

- Механизм зависит от Flexberry.
- Регистрация аудита встроена в `FlexberryModule`; как самостоятельный модуль она не поставляется.
