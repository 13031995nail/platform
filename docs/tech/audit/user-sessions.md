## Назначение

Модуль предоставляет возможность создания, ведения и управления сессиями пользователей. Сессия создается при аутентификации в системе.

Опционально предоставляется фильтр авторизации, в котором выполняется проверка активной сессии. Если сессии нет, пользователю возвращается ответ об отсутствии авторизации.
