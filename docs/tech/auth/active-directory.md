# Аутентификация через Active Directory

* Дата создания: 2025-09-09
* Дата обновления:
* Версия: 1.0
* Статус: Идёт реализация

## Назначение

Модуль обеспечивает прозрачную и непрозрачную Windows-аутентификацию с использованием Active Directory и Kerberos. В исходном описании реализация рассчитана на Windows и IIS; поддержку развёртывания под Linux планируется добавить в дальнейшем.

## Участники и взаимодействие

- **Фронтенд:** пакет `@timepath/tmobis-windows-auth`, аутентификатор `windows`. Инициирует проверку доменной учётной записи на бэкенде.
- **Бэкенд:** пакет `Tmobis.Frameworks.Web.Auth.Windows`. Контроллер `api/auth/validate` получает доменную учётную запись через Kerberos и ищет связанные записи `User` и `Employee` в базе данных приложения.
- **Результат:** если соответствующая учётная запись найдена, бэкенд выдаёт JWT-токен аналогично обычной аутентификации.

## Условия развёртывания

Текущая реализация привязана к Windows/IIS, доменной конфигурации и HTTPS. Для работы необходимы доменная сервисная учётная запись с делегированием, SPN для адресов фронтенда и бэкенда, а также согласованные параметры проверки подлинности IIS. Подробности описаны отдельно: [настройка Active Directory в IIS](active-directory-iis.md).

## Ограничения и альтернативы

- Поддержка только IIS.
- Как альтернатива рассматривается встроенная в приложение аутентификация Negotiate.

## Требует уточнения

- Поведение двух вариантов Windows-аутентификации (прозрачной и непрозрачной).
- Условия сопоставления доменной учётной записи с `User` и `Employee`.
- Актуальность ограничения на IIS и состояние планируемой поддержки Linux.
