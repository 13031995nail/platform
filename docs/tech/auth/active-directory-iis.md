# Развёртывание аутентификации Active Directory в IIS

Этот документ сохраняет эксплуатационные сведения, которые неуместно помещать в архитектурный обзор или Outline. Он не является подтверждением применимости настроек к любой версии IIS и любой инфраструктуре.

## Общие требования

1. Сервер должен входить в домен.
2. Требуется сервисная доменная учётная запись с правами на делегирование.
3. Поддерживается только HTTPS: должны быть выпущены сертификаты и настроены привязки адресов фронтенда и бэкенда в IIS.
4. Для адресов фронтенда и бэкенда необходимо создать SPN на сервисную доменную учётную запись.
5. Для пулов приложений фронтенда и бэкенда в качестве удостоверения указывается сервисная доменная учётная запись.

## Фронтенд

- Режим управления пулом приложений: **классический**.
- Анонимная проверка подлинности: включена согласно источнику.
- Олицетворение: **прошедший проверку пользователь**.
- Проверка подлинности Windows: включена.
  - Расширенная защита: **выключена** согласно исходной инструкции.
  - Проверка подлинности в режиме ядра: включена.

## Бэкенд

- Режим управления пулом приложений: **встроенный**.
- Среда CLR: **4.0**.
- Анонимная проверка подлинности: включена согласно источнику.
- Проверка подлинности Windows: включена.
  - Расширенная защита: **выключена** согласно исходной инструкции.
  - Проверка подлинности в режиме ядра: включена.
- Для `system.webServer/security/authentication/windowsAuthentication` указан параметр `useAppPoolCredentials`.

## Что необходимо перепроверить

- Необходимость и объём делегирования сервисной учётной записи.
- Совместимость сочетания анонимной и Windows-аутентификации, олицетворения и режима пулов с текущим размещением компонентов.
- Обоснованность отключения расширенной защиты Windows-аутентификации: это **значимая для безопасности** настройка, которую нельзя без проверки переносить в новую среду.
- Конкретное значение `useAppPoolCredentials`: в исходном тексте назван параметр, но его значение не указано.
- В оригинале были две иллюстрации, доступные только через внутренние ссылки Outline `/api/attachments.redirect?...`; сами изображения не предоставлены, поэтому не перенесены.
