# Модуль обмена сообщениями через репозитории

* Дата создания: 2025-04-15
* Дата обновления: 2026-01-30
* Версия: 1.1
* Статус: Реализовано

## Архитектурное решение

Транспорт на основе репозитория преобразует сообщение в сохраняемую сущность с идентификатором и исходным содержимым сообщения и записывает её в постоянном хранилище через `IRepository`.

Базовый класс вторичного адаптера определяет общий алгоритм записи, а конкретный тип хранимого сообщения предоставляет преобразование сообщение → сущность.

Механизм предназначен как техническая основа для сценариев отложенной и повторной отправки, которым нужно переживать перезапуск процесса.

## Открытые вопросы

* конкретный адаптер хранилища (в документе оставлено `EF/Flexberry?`);
* необходимость общего преобразователя сообщение ↔ сущность, чтобы не плодить отдельные реализации вторичных адаптеров.
