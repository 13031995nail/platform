## Архитектурное решение

Адаптер WebAPI публикует зарегистрированные типы сообщений как эндпоинты Minimal API.

Маршрут строится из метаданных сообщения (группы/имени) либо имени типа. Семантика сообщения выбирает метод HTTP: запрос использует GET, команда/событие — POST.

Тело запроса десериализуется в зарегистрированный тип и передается сообщение диспетчеру сообщений, поэтому HTTP слой не содержит бизнес-обработки.
