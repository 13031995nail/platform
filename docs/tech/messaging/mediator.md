# Модуль медиатора

* Дата создания: 2025-04-08
* Дата обновления: 2026-04-01
* Версия: 4.2.13
* Статус: Реализовано

## Архитектурное решение

Вторичный адаптер для обмена сообщениями внутри процесса является адаптером по умолчанию.

По типу сообщения он получает зарегистрированные обработчики из DI:

* отправка с результатом и без результата направляются одному обработчику;
* рассылка направляется всем обработчикам;
* цепочка обработчиков собирает результаты нескольких обработчиков.

Текущая реализация использует средства рефлексии .NET для вызова обобщённых контрактов обработчиков.

## Компромисс

Решение фактически реализует шаблон «Медиатор», уже доступный в сторонних библиотеках. Исходный документ рассматривает MediatR/MassTransit как альтернативы.
