# Модуль отложенных и повторных сообщений

* Дата создания: 2025-04-15
* Дата обновления: 2026-04-01
* Версия: 4.2.13
* Статус: Реализовано

## Архитектурное решение

Отложенные сообщения — обёртка над обычным сообщением с моментом, после которого оно может быть выполнено. Запрос на отложенную отправку сохраняется в постоянном хранилище через `IRepository`. Периодическая проверка выбирает сообщения, срок которых наступил, и возвращает их в обычный диспетчер сообщений.

Механизм повторной обработки интегрируется с RabbitMQ DLQ: отказавшее сообщение преобразуется в событие повторной отправки, затем в отложенное сообщение и после задержки снова отправляется на обработку.

## Состав решения

Решение включает:

* общие контракты отложенных и повторных сообщений;
* постоянное хранение в репозитории для отложенных сообщений;
* периодическую проверку сроков выполнения;
* первичный адаптер RabbitMQ DLQ;
* преобразование повторной отправки → отложенное сообщение;
* готовый фоновый сервис, который связывает эти компоненты.

## Открытые вопросы

* реализация хранилища для сущностей отложенных сообщений;
