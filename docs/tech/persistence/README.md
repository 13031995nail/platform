## Архитектурная модель

Репозиторий является не зависящим от технологии интерфейсом доступа к хранилищу и работает с контрактами сущностей.

Он покрывает чтение по идентификатору, поиск и получение списков, проверку наличия, составление запросов, создание, обновление и удаление, подгрузку представлений и фиксацию изменений.

## Принцип расширения

Прикладной код зависит от интерфейса репозитория. Для конкретного хранилища создаётся адаптер, который создаёт экземпляр нужного типа сущности и переводит операции репозитория в запросы конкретного хранилища.
