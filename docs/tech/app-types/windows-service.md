# Службы Windows (`Tmobis.WinService`)

* Дата создания: 2026-05-18
* Дата обновления:
* Версия: 4.2.13
* Статус: Реализовано

## Назначение

Компонент настраивает приложение для работы в качестве службы Windows.

## Основные компоненты

- `WinServiceModule` — модуль для запуска в режиме службы Windows.
- `WorkerAppBuilder` — базовый сборщик воркеров.
