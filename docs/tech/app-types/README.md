## Назначение и устройство

Платформа предоставляет шаблоны для разных типов запуска приложения на основе `IHostApplicationBuilder`.

Базовая абстракция — `AppBuilderBase` из `Tmobis.Core.Application`. Есть два специализированных сборщика:

- `WebAppBuilder` — сборщик веб-приложений;
- `WorkerAppBuilder` — сборщик воркеров.

Подключаемые модули дополняют настройку соответствующего варианта запуска. Описанные в исходниках варианты:

| Тип приложения | Сборщик / подключение | Подробности |
| --- | --- | --- |
| Воркер | `WorkerAppBuilder` | [Воркер](worker.md) |
| Веб-приложение | `WebAppBuilder`, `WebFrameworkModule` | [Веб-приложения](web.md) |
| Служба Windows | `WorkerAppBuilder`, `WinServiceModule` | [Службы Windows](windows-service.md) |
