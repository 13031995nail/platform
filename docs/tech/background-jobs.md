# Модуль фоновых задач

* Дата создания: 2025-04-18
* Дата обновления: 2026-01-30
* Версия: 1.0
* Статус: Реализовано

## Архитектурное решение

Платформа использует стандартные фоновые службы .NET для разовых и постоянно работающих задач.

Плановые задачи вынесены в отдельный абстрактный механизм: конфигурация связывает тип сообщения с расписанием, а адаптер Quartz создает задания и при срабатывании отправляет соответствующее сообщение через слой обмена сообщениями.

## Архитектурная цель

Бизнес-операция плановой задачи описывается сообщением и его обработчиком, а Quartz остается заменяемым технологическим адаптером.

## Технологии

* стандартные `BackgroundService` / `IHostedService`;
* `Tmobis.Jobs.Scheduled`;
* адаптер `Tmobis.Jobs.Scheduled.Quartz`.
