## Техническое назначение

Модуль задает базовый контракт объекта работ.

## Структура

Базовый объект содержит наименование, адрес, актуальность и иерархическую связь. Расширение добавляет назначение объекта и связь с организацией.

Назначения объектов вынесены в отдельный справочник. Для использования объекта в других сущностях предусмотрен общий контракт ссылки на объект работ.
