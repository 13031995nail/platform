# Программа оценки готовности к ОП

* Дата создания: 2026-05-27
* Дата обновления:
* Версия:
* Статус: Реализовано

## Техническое назначение

Компонент реализует документ программы оценки готовности поверх базового акта и управляет связанными графиками, объектами и участниками.

## Основные потоки

* при создании программы формируются записи графика и состав участников;
* при создании записи графика формируется соответствующий набор объектов;
* при удалении записи графика связанные объекты удаляются;
* операции выполняются через обработчики событий сущностей и репозитории предметного слоя.
