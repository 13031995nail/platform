# Настройки

Экран `/settings` («Настройки») — аналог Ember `#/settings`. Роут регистрирует `CoreModule` (`hideInNav: true`), открывается из системного хедера.

Лейаут из двух списков:

1. **Грид акцентных кнопок** (`variant: 'action'`) — быстрые действия модуля.
2. **Список «кнопка + описание»** (`variant: 'row'`) — пункты с пояснением или текущим значением. Вместо кнопки можно передать кастомный `component`.

Пункты группируются по полю `group` (модуль / подсистема). Внутри группы сначала грид акцентных кнопок, затем строки с описанием. Группа «Общее» ядра идёт после групп модулей.

## Пункты из модуля

```tsx
import type { SettingsItem } from '@tmobis/core/settings/types';

getSettingsItems(): SettingsItem[] {
  return [{
    id: 'reports.reload',
    variant: 'action',
    group: 'Настройка справочников',
    groupOrder: 20,
    order: 10,
    caption: 'Перезагрузка справочников',
    onPress: () => { /* ... */ },
  }, {
    id: 'reports.clear-lists',
    variant: 'row',
    group: 'Настройка справочников',
    groupOrder: 20,
    order: 20,
    caption: 'Очистить настройки списков',
    description: 'Сброс сохранённых фильтров и сортировок',
    onPress: () => { /* ... */ },
  }];
}
```

Вклады модулей объединяются. При совпадении `id` побеждает поздний модуль. Роли (`roles`) фильтруются так же, как у экранов и плиток рабочего стола.

Вместо `onPress` можно задать `href` для перехода на другой экран.

Для кастомной строки:

```tsx
{
  id: 'my.toggle',
  variant: 'row',
  group: 'Мой модуль',
  caption: 'Уведомления',
  component: MyNotificationsRow,
}
```

`component` получает `{ item }` и рендерится вместо стандартной кнопки.

## Дефолтные пункты ядра

`CoreModule` добавляет группу «Общее»:

- Язык
- Тема
- О приложении
- Выход

Язык и тема сохраняются в AsyncStorage и применяются через `AppPreferencesProvider`.
