# Диспетчер сообщений

`CompositionRoot` собирает производителей из модулей и добавляет резервный
производитель WebAPI. Каждый модульный производитель объявляет `messageTypes`,
поэтому диспетчер проверяет `canSend()` только у производителей нужного типа,
сохраняя порядок модулей. Если ни один из них не принимает сообщение, оно
отправляется через WebAPI. Модуль возвращает производителей из
`getMessageProducers()`.

Провайдер может зарегистрировать производителя после создания через
`registerProducer()`. Метод возвращает функцию, удаляющую регистрацию.

```ts
const result = await useMessageDispatcher().send(new GetUser('42'));
```
