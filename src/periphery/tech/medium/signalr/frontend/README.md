#Подключение SignalR в прикладном проекте

##Установка

1. Перед началом работы убедитесь, что у вас установлен модуль платформы с SignalRConnection.
2. Так же убедитесь, что установлен пакет @microsoft\signalr.
3. npm устанавливает содержимое пакета в папке node_modules\@microsoft\signalr\dist\browser.
4. Скопируйте файл signalr.js из директории пакета в папку ~/public.
5. Добавьте ссылку на файл в index.html <script src="/signalr.js"></script>
6. В конфиге добавьте ссылку на ендпоинт сигналР => config.APP.backendUrls.signalr = backendUrl + "/signalr"

##Использование

!!!Важно отметить, что методы send и stop не ждут выполнение метода start, но зависят от состояния подключения!!! 
Если состояние не Connected, то в консоли выдадут ошибку по типу: "Cannot send data if the connection is not in the 'Connected' State."

1. Подключите сервис signalr

В файле, где требуется подключение к SignalR (Желательно выполнять при старте приложения):

import { inject as service } from '@ember/service';

signalr: service(),

2. Подключение к хабу

var signalr = this.get('signalr');
signalr.start() //без await, чтобы не стопить отрисовку
 
3. Подписка на события

Бэкенд отправляет сообщения в формате json в метод "ReceiveMessage".
Поэтому прослушиватель на клиенте может выглядеть следующим образом:

signalr.on('ReceiveMessage', (data) => {
  console.log('Новое сообщение:', data);
});


Пример возвращаемого значения data:

{"Context":{"text":"Привет!","Target":""}}


4. Вызов методов хаба

У хаба есть метод SendMessage.

Для отправки в него используется метод send().
В него важно передавать json объект, который потом преобразуется в строку.
- Атрибут $type представляет FullName типа, к которому надо преобразовать сообщение.
- Атрибут context хранит в себе данные сообщения.
	- Для SendMessage Важно указать Target, который хранит в себе айди целевого пользователя в SignalR.

Пример реализации:

const msg = {
  $type: 'test.GetMessage',
  "context": {
     "text": 'Привет!',
     "Target": '*сюда ключ пользователя, которому отправляется сообщение*'
  }
};
signalr.send(msg);


6. Отключение

signalr.stop();

Если у вас возникли вопросы или проблемы, обратитесь к документации модуля платформы или команде разработчиков.
