## Подключение на прикладной проект

Для того, чтобы подключить необходимый для работы Metabase пакет нужно:
- Добавить пакет @timepath/tmobis-business-intelligence в зависимости проекта фронта
- Добавить проект Tmobis.BusinessIntelligence в зависимости проекта бека
- Подключить проект фронта и бека, подключить модули
- Подключить локали на фронте
- Добавить в environment на фронте параметр config.APP.metabaseURL

Пример реализации с тестовым роутом и подключением всего необходимого есть здесь: [ссылка на commit](https://gitlab.timepath.ru/timepath/tmobis.mk/tmobis-mk/-/commit/5bdba83a5bd3a761705864a60220e380ee6a21f5)

## Использование на прикладном проекте

После подключения пакетов по инструкции выше доступен функционал:

- Компонент tmobis-dashboard-frame для отображения дашбордов на странице. Параметр - tmobisDashboardId, нужно придумать идентификатор для каждого нового дашборда в приложении. Можно использовать строку или guid.
- Роуты tmobis-dashboards и tmobis-dashboard для того, чтобы можно было сопоставлять id дашбордов в приложении и id дашбордов в Metabase. Позволяет изменять дашборды в приложении без вмешательства разработчика.  
Модель tmobis-dashboard:
- tmobisDashboardId - идентификатор дашборда в приложении tmobis, хардкод от разработчика
- metabaseDashboardId - идентификатор дашбора в metabase.
- note - опциональный комментарий
